Monocular Visual SLAM on a Raspberry Pi robot

OPEN SOURCE · THESIS

AI Specialization, Universidad de Buenos Aires · 2026

Problem
Localize a robot and map its surroundings using only a single camera — no wheel odometry, no depth sensor.
Solution
Two implementations: an ORB-based SLAM running on a Raspberry Pi robot, and a PC benchmark comparing SIFT in classic OpenCV versus Kornia.
Highlights
Camera calibration, tuning of feature and matching parameters to stabilize rotation estimates, and a single-threaded event loop sized for embedded hardware.
